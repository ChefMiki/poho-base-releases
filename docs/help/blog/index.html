What’s new in PoHo

Every version, what changed and why.

  • 2026-10-11Built for computers we never seeWhy one user saw only four of his skills, what we changed so it does not happen again, and the beta channel.
  • 2026-10-11A library for your skills, and a map that comes alivePoHo now knows every skill and plugin on your computer, suggests the ones that fit each project, and shows what a project is running.
  • 2026-10-08PoHo Base 0.2.3A new loader made of the PoHo mark: your projects slide in and the roof lands over them, on start-up and in every long wait
  • 2026-10-07PoHo Base 0.2.2Open site: one click from Home or a project to its running dev server (localhost) or its public website
  • 2026-10-07PoHo Base 0.2.1A welcome screen with a short animation greets you after this update; open it again any time from the ⚙ menu or Settings
  • 2026-10-06PoHo Base 0.2.0A new look: one big Continue on Home, a clear top bar instead of the sidebar, bigger type on large screens
  • 2026-10-06PoHo Base 0.1.7Safer with downloaded projects: a project’s own git settings can no longer make PoHo run a program while it scans, and website pictures can no longer reach your local network
  • 2026-10-05PoHo Base 0.1.6Choose your terminal: Windows Terminal, WezTerm, Alacritty or a plain window, with PowerShell 7, Windows PowerShell, Git Bash or Command Prompt (Settings → Preferences)
  • 2026-10-05PoHo Base 0.1.5Pick up where you stopped: one button starts Claude Code, Codex, Gemini CLI, OpenCode or Antigravity already knowing where the last session ended, in any tool
  • 2026-10-05PoHo Base 0.1.4Antigravity: PoHo reads its plans, task lists and walkthroughs, so Claude Code or Codex can pick up where it stopped
  • 2026-10-05PoHo Base 0.1.3Find my AI work: PoHo lists only the folders where Claude Code, Codex and other agents worked, and you approve each one
  • 2026-10-05PoHo Base 0.1.2Updates arrive on their own: PoHo checks when you open it, tells you when one is ready, and installs it while idle in the tray
  • 2026-10-04PoHo Base 0.1.1Report a bug, idea or question from the app, with screenshots
  • 2026-10-04PoHo Base 0.1.0Finds your projects and remembers your AI coding sessions
