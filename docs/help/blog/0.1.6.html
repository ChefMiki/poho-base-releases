PoHo Base 0.1.6

  • New Choose your terminal: Windows Terminal, WezTerm, Alacritty or a plain window, with PowerShell 7, Windows PowerShell, Git Bash or Command Prompt (Settings → Preferences)
  • New Try it: one click checks that PoHo can start AI tools in your terminal
  • Better PowerShell 7 first: AI tools and updates start in PowerShell 7 when it is installed, so long notes and non-English text arrive intact
  • Better Faster Claude Code in Cursor: Cursor starts opening right away and the notes are written while it starts
  • Fixed Claude Code in a terminal did nothing on computers without Windows Terminal: the PowerShell window now opens, and when a terminal does not start, PoHo tries the next one
  • Fixed Antigravity sessions no longer offer a Continue in terminal button that cannot work
