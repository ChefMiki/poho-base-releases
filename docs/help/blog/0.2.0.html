Blog · 2026-10-06 · version 0.2.0

PoHo Base 0.2.0

  • New A new look: one big Continue on Home, a clear top bar instead of the sidebar, bigger type on large screens
  • New Project map: open a project and see what it is made of — the AI agents and skills it uses, git, GitHub, its dev server and services — and click anything for details
  • Better Projects: five clear columns with one status per project, Continue the last chat right from the list, one Filter menu, picture cards
  • Better History: your week as one card with a copyable report, only the months you actually worked, where the time goes
  • Better Project pictures stay put after a restart or an update; a blank or half-restored window never replaces a good picture
  • Better Fewer, clearer buttons in Projects: one ⋯ menu per project names every action in words, and a click on the row opens the project
  • New Remove from PoHo: hide a project you no longer want to see, after a clear “are you sure?”; its files are never touched and it waits under Archived
  • New See which projects are running and on which address (localhost:5173, :3000…), and open it with one click
  • Fixed Starring the project you were just working on now shows it in Favorites on Home
  • Fixed Your AI tools and connections are back on Home
  • New Search by meaning: type “payments” and find the chat about a Stripe checkout bug, in any language. Runs on your computer with a small free model (Settings → AI)
  • Better Stars, stages and Remove show instantly, and Continue shows a spinner until your editor opens, so a second click no longer opens a second window
  • Better When something breaks, only that part of the screen says so and the rest keeps working. Next time PoHo asks once whether to report it
  • Better AI agents asking PoHo for past sessions now find them by meaning too
