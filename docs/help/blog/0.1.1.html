Blog · 2026-10-04 · version 0.1.1

PoHo Base 0.1.1

  • New Report a bug, idea or question from the app, with screenshots
  • New Reports include this computer's details, so we know what to optimize for
  • New AI add-on checks whether this computer can run local AI and suggests a model
  • New Finds Ollama and the models you already have, and picks the best one for this computer
  • New New project: start from a template, with git and notes for AI agents, opened where you like
  • New Switch tool: continue in Codex, Gemini CLI or another Claude account, briefed on where you stopped
  • New Several Claude accounts, with lanes so they can work on one project side by side
  • New Search all your AI sessions from Ctrl+P, even inside full conversations
  • New PoHo as a tool for Claude Code, Cursor and Codex: they can ask where you stopped (MCP)
  • New Write agent notes: CLAUDE.md and AGENTS.md filled from what PoHo knows
  • New Taskbar Jump List and tray: continue a recent project in one click
  • New End-of-day reminder when today's work is not committed
  • New Your week in Insights, with a report you can copy
  • New Security check for npm packages in project Health
  • New Run warns when the port is taken and offers a free one
  • New Claude usage without signing in: this 5-hour window, when it resets, and a warning before the limit
  • New Live now: see which agent is working, waiting for you or finished, with notifications
  • New Snapshots before every AI session; see what a session changed and restore any file
  • New Session archive: conversations Claude Code deletes after 30 days stay searchable and restorable
  • New Agents get your project memory back right after Claude compacts a long conversation
  • New Health warns about .env files git would publish, drifting agent notes, cloud-synced folders and expiring domains
  • New Ready to run: Node version, missing packages and Python environments, with one-click fixes
  • New Running & ports: who holds which port, and ports Windows reserves
  • New Archive a project with one line for future you
  • Better Enter in quick open continues your last AI session
  • Better Unpushed commits show in Needs you and the evening reminder
  • Fixed Folders inside a project (scripts, skills, src) no longer show up as separate projects
