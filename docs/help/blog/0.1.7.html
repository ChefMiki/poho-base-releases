Blog · 2026-10-06 · version 0.1.7

PoHo Base 0.1.7

  • Fixed Safer with downloaded projects: a project’s own git settings can no longer make PoHo run a program while it scans, and website pictures can no longer reach your local network
  • Better Smoother: PoHo redraws only what changed, stays responsive while scanning, and animations are shorter, play once and answer every press
  • Better Works with the keyboard and screen readers: every button has a name, dialogs keep focus, Escape closes only the top window
  • Fixed Continue buttons appear only when the tool is installed, and say so when something goes wrong; missing pictures show the project instead of a broken image
  • Fixed Updates can no longer install a half-downloaded file, a terminal no longer runs a command twice on a slow start, and alerts no longer wait for the next event
  • Better Clearer privacy notice and terms: every connection PoHo makes is listed, with your rights and how to reach us
  • Better Fewer notifications: “Claude knows where you stopped” comes only for a new chat and only the first few times, and notifications are signed PoHo Base instead of Electron
  • New Restart session: installed new skills or plugins for Claude Code? One click closes the chat and opens it again with them loaded, then shows what is new since the chat started; the conversation stays
  • New A new Settings: categories on the left, one page at a time, and every setting explains what it does
  • Better Focused on getting back to work: Today shows where you stopped, your favorites and what is in progress; a project opens with where you stopped and what it is, and the details wait behind one click
  • Better Fewer buttons: one Open menu for Cursor, VS Code, the terminal and the folder; your AI tools moved to Settings → AI agents; the sidebar shows only what you use
  • New Live projects pulse: green when a project is running, blue when an AI agent is working on it, in the sidebar, on cards and on Today
  • New Claude usage on Today: tokens today and which projects they went to, the 5-hour window and the week, with exact limits from Claude when you turn them on
  • New Favorites: star a project anywhere and it gets its own row on Today and its own list at the top of the sidebar
  • New Logos for every AI tool and terminal: Claude, Cursor, Gemini, OpenCode, Ollama, GitHub and more
  • Better A loading screen, livelier details: the star pops, meters fill in, cards arrive in turn
  • Better Safer AI agents: when they ask PoHo, they see only the project they work in, and keys, tokens and passwords are removed from every answer, bug report and AI summary
  • Better Safer website pictures: a website found in a repo is only opened when it is on the public internet, never an address on your computer or network
  • Better Your configs are safe: PoHo never rewrites a Cursor, Claude or Codex config it cannot read exactly, and keeps a copy before every change
  • Fixed Restoring a file from a snapshot never overwrites your current work without a copy, and .env files with secrets are no longer stored in snapshots
  • Fixed Folder and file names can no longer start commands in a terminal, and a security check can no longer run a program planted in a project
