Blog · 2026-10-11 · version 0.2.5

Built for computers we never see

Soon after 0.2.4 came out, one of our first users opened the new skills library and saw four skills. He has many more.

The library worked on the computer it was built on. His skills came from his claude.ai account, which Claude Code keeps in a folder of its own, and PoHo did not look there. Nothing in our checks had a computer like his.

That is the honest story behind 0.2.5, and it changed how PoHo is made.

What is fixed

  • Skills synced from your Claude account now show up, and the Skills page lists Where PoHo looked, with how many skills it found in each folder.
  • The project map comes alive without Run: a dev server or Claude Code started in a terminal counts, found by the folder it works in.
  • “AI working” stays on while the AI thinks or runs a long command.
  • On Home you can pick which project the Discover card is for.

How we check now

Every version now has to pass a quality gate before it can be published. The release script runs it itself and refuses to publish if anything fails:

  1. Tests against a set of fake computers: a brand-new machine, a beginner, someone whose skills only come from their Claude account, plugins in different file formats, a user named “Đorđe Čačak” with projects full of č, ć and đ, Documents on OneDrive, a power user with more than a hundred skills, Obsidian installed and Obsidian with a broken settings file.
  2. The real app, started as another computer: first start, a new user with a few projects, and an existing user after the update.

These tests already found problems nobody had seen: a skill saved by Notepad with an invisible byte at the start lost its description; another Claude Code version’s plugin file could empty the whole library; a missing Windows setting could have pointed the uninstaller at the wrong folder. All fixed, all now tested.

When a user finds something we did not think of, that computer becomes a new fake machine, so the same problem cannot come back.

Beta versions first

Settings → Updates → Get beta versions first. New versions now go to beta users before everyone else. If something is wrong, it is found by a few people who asked for it, not by everyone.

Everything in 0.2.5

  • Fixed Skills from your Claude account (synced by Claude Code) now show in the Skills library; it also lists where it looked
  • Better The project map comes alive without Run: a dev server or Claude Code started in a terminal counts, by the folder it works in
  • Better “AI working” stays on while the AI thinks or runs a long command
  • New Pick the project on Home’s Discover card
  • New Beta versions first: Settings → Updates → Get beta versions first
  • Fixed Skills saved with a byte-order mark (Notepad) keep their description; other plugin file formats no longer empty the library
  • Fixed Safer changes to Claude Code’s settings file and a safer uninstall
  • New A help center with a map of the app, and this blog
