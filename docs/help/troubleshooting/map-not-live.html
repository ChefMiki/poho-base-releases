Troubleshooting

The map doesn’t come alive

When the project map shows something running, and why it may stay quiet.

The map comes alive only while it is open and PoHo’s window is visible. Then PoHo checks every 5 seconds what runs in the project; if it finds a program working there, an AI working or the dev server running, the centre turns green and breathes.

How PoHo finds what runs in a project

A program counts for a project when:

  • it works in the project folder (its current folder is the project or a folder inside it), or
  • its command line or program path names the project folder, or
  • it belongs to an AI chat PoHo knows,

plus every program those start. So a dev server you start in a terminal (node server.js, python app.py) counts even if you didn’t start it from PoHo.

These never count: PoHo itself, a terminal that only sits in the folder (what it starts does count), git and Windows system programs. Editors such as VS Code or Cursor are shown under “Open in” instead, because one editor serves many projects.

An AI that PoHo sees working, from its chat file or the briefing connection, also makes the centre come alive, even when its program isn’t found. See PoHo doesn’t show my AI working.

Why it may stay quiet

  • The map is not open, or PoHo is minimised. PoHo looks only while you watch.
  • The program runs somewhere else. If it started in another folder and doesn’t name the project folder, PoHo can’t tell it belongs to the project.
  • PowerShell is limited on your computer. PoHo asks Windows through PowerShell. On computers that limit PowerShell (Constrained Language Mode, often set by a company), PoHo can’t read each program’s current folder; it still finds programs whose command line names the project folder. If PowerShell is blocked completely, the map can’t see programs at all.
  • It is not Windows. The live map works on Windows only.

Tip: To be sure a dev server shows up, start it with Run the dev server in the map’s dev server panel, or start it from a terminal opened in the project folder.
