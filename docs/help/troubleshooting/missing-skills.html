Troubleshooting

I don’t see all my skills

Where PoHo looks for skills, why one can be missing, and how to check with Where PoHo looked.

PoHo lists only skills in the folders it knows about. Open Projects → Skills, scroll down and open Where PoHo looked: it lists every folder PoHo searched and how many skills it found in each.

Where PoHo looks

A skill is a folder with a SKILL.md file in it. PoHo looks in:

  • Your skills folders: ~/.claude/skills, ~/.agents/skills, ~/.cursor/skills and ~/.codex/skills.
  • The same four folders inside every project PoHo knows.
  • Skills synced from your claude.ai account, in ~/.claude/skills/synced. Their source shows as “Your Claude account”.
  • Installed Claude Code plugins.

Hidden folders, such as .trash or .git, are skipped.

Why a skill can be missing

  • The project is not in PoHo. Skills inside a project folder are found only when PoHo knows that project. Add its folder: Add your project folders.
  • The project is archived, or its folder is gone. PoHo does not look inside it.
  • The skill is somewhere else. A skill outside the folders above is not found.
  • The folder has no SKILL.md. Without it, PoHo does not see a skill.
  • The list is out of date. Click Look at your skills again (the refresh button next to the search field).

Check it

  1. Open Projects → Skills.
  2. Open Where PoHo looked at the bottom.
  3. Find the folder where you expect the skill. If it is not listed, PoHo does not look there, or the folder does not exist. If it shows 0, PoHo found no skill folder with a SKILL.md in it.

Tip: A plugin installed for a folder PoHo does not know counts as an “other folder” in the plugin’s details.

Still missing? Report a problem and say which folder the skill is in.
