Troubleshooting

Windows blocks PoHo

Why Windows may warn about PoHo, and what to do if it happens.

If Windows shows a warning or refuses to start PoHo, first make sure you downloaded it from PoHo’s official download link. Then use Windows’ own dialog to allow it, or report the problem to us.

Why it can happen

Windows has guards, such as SmartScreen and Smart App Control, that can warn about or stop programs downloaded from the internet. What PoHo is:

  • PoHo Base.exe is the standard Electron program, only renamed. PoHo’s own code sits next to it. The exe has no Windows code signature of PoHo’s own.
  • Updates never change PoHo Base.exe. They replace only PoHo’s code, and only when it is signed by PoHo’s developer. PoHo checks that signature itself; Windows does not.

If Windows warns you

  1. Check where the file came from. The download is PoHo-Base-win-x64.zip from PoHo’s releases on GitHub (the Download button on PoHo’s website).
  2. Unpack the zip, then start PoHo Base.exe.
  3. If SmartScreen shows “Windows protected your PC”, click More info, then Run anyway.

After the first start, PoHo installs itself for your user (Accept and install) and makes Desktop and Start menu shortcuts.

If Smart App Control blocks it

Please don’t turn off Windows protection to get past it. Tell us instead: open an issue on PoHo’s releases page on GitHub (github.com/ChefMiki/poho-base-releases) with your Windows version and the exact message. If PoHo starts, you can use Report a problem.

Note: PoHo installs into your own user folder, %LOCALAPPDATA%\Programs\PoHo Base.
