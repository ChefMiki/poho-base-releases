Troubleshooting

Report a problem

Send a bug, an idea or a question from inside PoHo, and see exactly what is sent.

Open Settings and more (the gear in the top bar) → Report a bug. Describe what happened, add a screenshot if it helps, and click Send.

Send a report

  1. Click the gear in the top bar, then Report a bug.
  2. Pick Bug, Idea or Question.
  3. Write a Title and what happened. For a bug, add How to make it happen again if you can.
  4. Add screenshots with Add screenshot, paste them with Ctrl+V, or drag them in (up to 5 PNG, JPEG or WebP images, 2 MB each).
  5. Click Send, or Copy instead to copy the report and send it your own way.

The note above the buttons tells you where the report goes. Today that is usually a GitHub issue you post yourself: PoHo opens it in your browser, filled in, and you press Submit there. It needs a free GitHub account. Screenshots are not added to the issue for you: drag them into it on GitHub.

Warning: GitHub issues are public. Leave out anything private from your title, text and screenshots.

What is sent

Click What is sent to see every field before you send. With Include details about this computer on (the default), the report includes:

  • PoHo’s version and how it is installed
  • your Windows version, computer model, processor, memory, graphics and screen
  • PoHo’s anonymous device ID, made when PoHo was installed
  • how PoHo’s AI add-on is set up, and how many projects and sessions PoHo knows
  • recent errors from PoHo’s log

Turn the switch off to send only what you wrote.

How PoHo keeps it safe:

  • Secrets such as keys, tokens and passwords are removed from the error log, your home folder is replaced with %USERPROFILE%, and file names are replaced with “…”.
  • PoHo adds no user name, serial number or MAC address, and no source files.
  • Your own title, text and screenshots are sent as you wrote them.
  • The report is saved on your computer first, so a failed send loses nothing.

When PoHo crashed

PoHo keeps a crash log on your computer and never sends it by itself. After a crash, the next start asks once: “PoHo hit a problem”. Click Report it to open the report form, filled in, with the last crashes in its technical details.
