Work with AI agents

Restart a chat with fresh skills

Close a Claude Code chat and open it again so it loads skills, plugins and settings installed since it started; the conversation stays.

A chat loads its skills, plugins and settings when it starts, so anything you install later is missing from it. Restart closes the chat and opens it again with everything new. The conversation stays.

Restart the last chat of a project

  1. Open the project (or use the big card on Home).
  2. Click More ways.
  3. Choose Restart this chat.
  4. Click Restart.

This option is there when PoHo can reopen the project’s last chat.

Restart any Claude Code chat

  1. Open the project and go to the Sessions tab.
  2. Find the chat and click Restart.
  3. Click Restart in the dialog.

What you see

PoHo shows Closing the chat, then Opening it again, then Restarted. Below that:

  • New since the chat started at … lists the skills and plugins that arrived after the chat began. Those are now available.
  • A warning if some plugins are installed for this project only and won’t load where the chat runs. Install them for all projects to use them there.
  • Everything it loads folds out the full list.

If the chat wasn’t running, PoHo simply opens it.

Note: If the AI is answering right now, that answer stops. In Cursor or VS Code the chat stays on screen; your next message continues it with everything new.

Tip: In a Claude Code chat that is open, you can also type /reload-plugins to pick up new plugins.

What PoHo touches

Only the processes running that one chat. PoHo never edits the conversation and never changes your skills or plugins.

New skills come from Install and update skills.
