Work with AI agents

What your AI is told when a chat starts

New Claude Code and Cursor chats get a short briefing from PoHo on the project and where you stopped; turn it on or off per tool.

When you start a new chat in Claude Code or Cursor, PoHo hands the AI a short briefing about the project, so you don’t have to explain where you stopped. You turn it on once per tool in Settings → AI agents → Agent memory.

What the briefing contains

Only facts PoHo already knows about the project, and only the lines it has something for:

  • what the project is
  • your last AI session, from any tool, with its summary
  • what was left open last time
  • commits made since that session
  • files that are not committed yet
  • your own notes on the project
  • how to run it
  • skills that fit this project, so the AI can use one when the task matches (Skills that fit a project)
  • a few earlier sessions

It ends by telling the AI that the files in the repository are the source of truth. The briefing is background, not orders.

Claude Code also gets a fresh briefing right after it compacts a long conversation.

Turn it on or off

  1. Open Settings (Ctrl+,) and go to AI agents.
  2. Under Agent memory, find Briefing at the start of a session.
  3. Click Connect next to Claude Code or Cursor Agent. Click Disconnect to turn it off.

The welcome screen offers the same choice as Tell AI agents where I stopped.

Note: Connecting works only in the installed app. Chats that are already open don’t get the briefing; start a new one.

What PoHo changes on your computer

PoHo adds its own small hook to Claude Code’s settings (~/.claude/settings.json) and to Cursor’s hooks file (~/.cursor/hooks.json). Hooks from you or other tools stay as they are, and PoHo keeps a one-time backup of each file next to it. Disconnect removes only PoHo’s entries. Nothing is sent over the internet.

The same hook lets PoHo see when the AI is waiting for you or has finished, for notifications. Before a new Claude Code session in a git project, PoHo saves a snapshot: see Snapshots before AI sessions.

The first few times, PoHo shows a notification such as “Claude knows where you stopped in …”. If you start a chat in a folder PoHo doesn’t know yet, it offers to add that folder so the next chat starts briefed.

Want the AI to ask PoHo questions during the chat too? See Let your AI ask PoHo (MCP).
