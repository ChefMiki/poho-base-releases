Skills

Install and update skills

Install a skill from Discover into your skills folder, and update the ones PoHo installed.

Click Install next to a skill in Projects → Skills → Discover. PoHo puts it in your skills folder, ~/.claude/skills, so every project gets it.

Install a skill

  1. Open Projects → Skills → Discover.
  2. Click a repository to open it.
  3. Click Install next to a skill marked Not on this computer.
  4. If the skill runs scripts, PoHo asks first. Read them on GitHub, then confirm.

What PoHo does:

  • It takes the skill as it is at the repository’s latest commit and pins it to that commit. A SOURCE.txt file in the skill’s folder notes where it came from and that PoHo installed it.
  • It never replaces anything. If you already have a skill with that name, it stops and tells you: “PoHo never replaces it.”

Use it in a chat

New AI chats load the skill. In a chat that is already open, type /reload-plugins, or use More ways → Restart this chat. See Restart a chat with fresh skills.

Check for updates

  1. Open Projects → Skills.
  2. Click Check for updates.

PoHo asks GitHub whether skills in your skills folder with a pinned source changed. It looks only at changes to the skill’s own folder, so other commits in the repository don’t count. Skills with a newer version get an Update chip. This works for skills PoHo installed and for skills whose source note you wrote yourself.

Update a skill

Open the skill’s row. You see what is newer on GitHub, then:

  • Update, for skills PoHo installed in ~/.claude/skills. PoHo downloads the new version, moves the old one to its backups and puts the new one in place. If something goes wrong, the old one goes back.
  • See the changes on GitHub, for every other skill. PoHo only updates skills it installed; update the others yourself.

Note: The old version is kept in PoHo’s own folder, %APPDATA%\PoHo Base\skill-backups. PoHo never deletes your files.

After an update, new AI chats load the new version.
