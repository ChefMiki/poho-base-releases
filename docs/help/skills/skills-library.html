Skills

Your skills library

See every agent skill and plugin on this computer, where it came from, which projects have it and how often your AI used it.

Open Projects → Skills to see every skill and plugin on this computer in one list. PoHo only reads these folders: it never installs, changes or removes a skill unless you click Install or Update yourself.

You can also get there from Home → Your tools or History → Skills and tools you use, with the Skills library link.

The four numbers

  • skills, and how many of them your AI used
  • plugins
  • unused for 2+ months (and how many for 6+)
  • with no known source

The tabs

  • All, Used and Unused (not used for two months or more, longest first).
  • Every project: skills in your own skills folder, so every project gets them.
  • Some projects: skills that live only inside certain projects.
  • Worth a look: skills with different versions, copied into several projects, copied into a project while also in your skills folder, or with an unknown source.
  • Plugins: installed Claude Code plugins and which projects they are installed for.
  • Discover: skills on GitHub. See Find new skills.

The search field looks at a skill’s name, purpose and source.

A row’s details

Click a row to open it. You see the full description (the author’s own words), why it is worth a look, Where it came from (with a link), Where it lives (every folder, each with Show in folder) and How often your AI used it.

The bin mark

A skill nobody used for 6 months gets a bin mark: “6+ months unused” or “Over a year unused”, and “a candidate to remove”. PoHo never removes it. Use Show in folder if you want to remove it yourself.

Note: Use counts come from the AI chats PoHo has read. The page tells you since when, so a skill is never called unused for longer than PoHo can know.

Compare versions

When the same skill exists in different versions, Compare versions shows what changed from the older to the newer one, and which one to keep.

Check for updates

Check for updates asks GitHub whether skills with a pinned source have a newer version. Skills with one get an Update chip. See Install and update skills.

Where PoHo looked

At the bottom, Where PoHo looked lists every folder PoHo searched and how many skills it found there. If a skill is missing, start there: I don’t see all my skills.
