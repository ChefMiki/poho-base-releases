Skills

Find new skills

Browse the most starred and rising skill repositories on GitHub and see which of their skills you already have.

Open Projects → Skills → Discover to browse public skill repositories on GitHub. For each one, PoHo shows which skills you already have and lets you install the others.

The lists

  • Most starred: skill repositories on GitHub, by stars.
  • Rising, made in the last 60 days: new repositories, by stars gained per day.
  • For <project>: shown when you come from a project (the Home card or a project page). It lists skills you already have that fit the project but were not used there yet, and repositories on GitHub that match what the project is made of.

Use Look again to fetch the lists again. The search field filters them too.

The marks on a repository

  • You have N: how many of your skills and plugins came from this repository.
  • A short tag such as a technology name: the repository matches what your project is made of.

Open a repository

Click a repository to see:

  • Open on GitHub, its stars, when it was made and its last change.
  • Skills in it: every skill, with its description.
  • For each skill, where you have it: “You have it in every project”, the projects it is in, or “On this computer”, and how often your AI used it. If yours came from somewhere else, it says so.
  • Not on this computer and an Install button for the skills you don’t have. See Install and update skills.

“Runs scripts”

Some skills contain programs (for example .py, .js, .sh or .ps1 files) besides their instructions. PoHo marks them “Runs scripts, read them before you install” and asks you before installing one.

Warning: A skill with scripts can run them on your computer when your AI uses it. Read them on GitHub first.

What goes over the network

Discover asks GitHub only when you open it, or when Show rising skills here is on in the Home card. It sends no information about you or your projects; matching your skills happens on your computer. If GitHub asks PoHo to slow down, you see “GitHub asks to wait a minute before more lookups.”
