Skills

Skills that fit a project

How PoHo picks the skills that suit a project, and how to tell your AI about them.

PoHo suggests skills from your own library that suit each project, and you choose which ones your AI is told about when a chat starts. No AI and no network are used for this; it all happens on your computer.

How “fits this project” works

PoHo compares what the project is made of with what each skill says it does:

  • The project: the technologies PoHo found in its folder (for example Shopify, Liquid or .NET), plus its description and summary.
  • The skill: its name and the description in its skill file.

Skills rank higher when:

  1. Your AI already used them in this project (“Used 2× here”).
  2. They were used in a similar project, one that shares its technologies.
  3. Their description names the project’s technologies (“Matches Shopify, Liquid”).
  4. They suit the kind of project, such as an online store, a website or a Windows app (“Fits an online store”).
  5. They are general skills for security, interfaces or tests.

The reason is always shown next to the skill.

On Home

The Discover new skills for <project> card shows up to three skills that fit the project you work on and were never used in it. Click the project name to pick another project. Discover skills opens Discover for that project.

Show rising skills here also lists new GitHub skill repositories that match the project; Hide rising skills turns that off. It looks up public repositories only; nothing about you is sent.

On the project page

Open a project, then Setup → Skills:

  • Used here: skills your AI already used in this project.
  • Fits, not used here yet: skills that suit it.

Each skill has two controls:

  • Tell AI: when it is on, PoHo names the skill to your AI when a chat starts in this project. PoHo turns it on for the best fits by itself; switch any of them on or off. A skill marked “not installed for this project” must be installed for the project first.
  • Copy (the clipboard button): copies “Use the <skill> skill to …”. Paste it into your AI chat and finish the sentence.

Discover more skills opens Discover for this project.

Note: Your AI is told only when PoHo’s briefing is connected. See What your AI is told when a chat starts.
