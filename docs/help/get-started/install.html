Get started

Install PoHo

Download the zip, run PoHo Base.exe once, and it installs itself for your Windows user with no admin rights.

Download PoHo Base as a zip, open PoHo Base.exe from it, and click Accept and install. PoHo installs itself for your Windows user, with Desktop and Start menu shortcuts. You do not need admin rights or an account.

PoHo Base runs on Windows 10 and 11. It is free.

Steps

  1. Download PoHo-Base-win-x64.zip. This link always gets the newest version.
  2. Unzip it anywhere, for example in your Downloads folder.
  3. Open the PoHo Base folder and double-click PoHo Base.exe.
  4. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  5. On Welcome to PoHo Base, choose what PoHo may do. See The first start.
  6. Tick I have read and accept the Terms of Use and the Privacy Notice.
  7. Click Accept and install.

The window closes and the installed PoHo opens. You can now delete the downloaded zip and folder.

Note: Windows may warn you because PoHo Base is a new app and is not code-signed. The updates PoHo installs later are signed by its developer, and PoHo refuses any that are not. See Updates and beta versions.

Where it goes

PoHo installs into %LOCALAPPDATA%\Programs\PoHo Base, inside your own user folder. It adds a Desktop shortcut and a Start menu shortcut. Nothing else on the computer changes, and it never touches your project files.

If you already have PoHo installed

Running a newer download installs over the old copy: PoHo asks the running one to close first. Your projects, notes and memory stay.

Remove it

Open Settings → Privacy & safety → Start over or remove PoHo and, under Uninstall PoHo Base, click Uninstall. It removes the app, its shortcuts, start-with-Windows and its Claude Code and Cursor hooks. Tick Also forget what PoHo remembered if you want PoHo’s own memory gone too, then click Uninstall again. Your project files are never touched.
