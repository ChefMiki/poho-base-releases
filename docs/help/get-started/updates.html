Updates and beta versions

PoHo downloads signed updates on its own; restart to use one, go back one version if it gives you trouble, or get beta versions first.

PoHo updates itself. When a new version is downloaded and checked, a card says “PoHo Base X is ready”: click Restart now, or simply keep working and it installs when you quit.

How updates arrive

PoHo looks for a new version a minute after it starts and then every 30 minutes. It downloads the update in the background and checks it before offering it.

  • Signed updates: every update is signed by PoHo’s developer. An update that is not signed, or was changed on the way, is refused.
  • When it is ready you get the card and a desktop notification. Click Restart now to switch at once, or close the card: the update installs the next time PoHo quits.
  • If PoHo waits in the tray with nothing running and no AI chat going, it can install the update on its own and stay in the tray.
  • Before every switch, PoHo copies its own memory (projects, notes, sessions), so nothing is lost.

After an update, What’s new in PoHo Base shows once, with every change since the version you had.

Check by hand

  1. Open Settings → Updates.
  2. Click Check for updates.

The line under the version says what happened, for example “You have the newest version.” When an update is ready, the button becomes Restart now, and the Updates page shows a green dot.

Go back one version

If a new version gives you trouble:

  1. Open Settings → Updates.
  2. Under Go back, click Go back next to Go back to version X.
  3. Confirm.

PoHo restarts on the older version. Your projects, notes and memory stay. The version you left is skipped until a newer one comes out.

Note: Go back appears only after an update, and goes back one version.

Get beta versions first

New versions go to beta users before everyone else, to catch problems early.

  1. Open Settings → Updates.
  2. Turn on Get beta versions first.

Betas are signed like every update, and you can go back one version if a beta gives you trouble. Turn the switch off to get only regular versions again; PoHo then offers the next regular version newer than the one you have.

Tip: If an update does not arrive, see An update doesn’t arrive.
