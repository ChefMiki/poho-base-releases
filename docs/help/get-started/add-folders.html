Get started

Add your project folders

Add a project folder, or a folder that holds many projects, and PoHo finds the projects inside. It never searches your drives on its own.

Click Add folder on the Projects page, then drop folders in or click to choose them. PoHo finds the projects inside and adds a page for each. It only looks in folders you add, and never searches your drives on its own.

Add a folder

  1. Open Projects in the top bar.
  2. Click Add folder.
  3. Drop one or more folders on Add project folders, or click the folder button to choose them.

You can add a single project, or a folder that holds many projects, such as C:\Users\you\code. PoHo looks inside for git repos and project files like package.json, pyproject.toml, Cargo.toml, go.mod, CLAUDE.md or AGENTS.md. Each one becomes a project.

PoHo reads project names, READMEs and git status. Nothing is uploaded.

Folders where your AI worked

When an AI tool works in a folder PoHo does not know yet, a small card appears at the bottom right: “Claude Code worked in my-app”. Click Add to PoHo to add it as one project, or Don’t add to stop being asked about it.

If PoHo lists a lot of folders (more than 150), it offers Choose folders so you can keep only the ones where you worked with AI, or Keep all.

Find projects you added later

PoHo looks again every 15 minutes and when you start it. To look right now, open ⚙ → Look for new projects.

Manage your folders

Open Settings → Projects & folders.

  • Folders PoHo reads lists every folder, with how many projects PoHo found in it. Add folder adds another.
  • The X next to a folder (Stop watching this folder) makes PoHo forget that folder’s projects. The files on disk are not touched.
  • Keep only my AI work keeps only the folders where you worked with AI, plus projects you starred, wrote notes for or archived.
  • Scan depth sets how many folder levels below an added folder PoHo looks: 2 to 6, 4 by default. Raise it if projects deep in a folder are missing. Folders added from your AI work are one project each and are not searched.

Note: Removing a folder or a project only changes what PoHo remembers. PoHo never deletes your files.
