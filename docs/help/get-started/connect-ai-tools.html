Get started

Connect your AI tools

PoHo remembers chats from your AI coding tools on its own; connect Claude Code and Cursor so new chats start knowing where you stopped.

Most AI tools need no setup: PoHo reads the chats they save on your computer. Connect Claude Code and Cursor as well, and every new chat in them starts already knowing the project and where you stopped.

What works on its own

With Read my AI coding sessions on (see The first start), PoHo reads the chat history of:

  • Claude Code
  • Codex
  • Gemini CLI
  • OpenCode
  • Antigravity (its plans, task lists and walkthroughs; not its conversations)

Each chat shows up on its project’s page under Sessions. Nothing is uploaded.

Tip: Claude Code deletes its old chats after 30 days by default. PoHo keeps a copy, so you can still find what you asked.

Connect Claude Code and Cursor

Connecting adds a small hook to the tool’s settings. When you start a new chat, the AI gets a short briefing: what the project is, your last session in any tool, what was left open, uncommitted files and your notes. PoHo also sees when the AI is waiting for you or has finished, for Live now on Home and for notifications.

  1. On Home, find the Your tools card.
  2. Click Connect next to Claude Code or Cursor.
  3. Read what it does, then click Connect.

You can also do it in Settings → AI agents → Agent memory, under Briefing at the start of a session: click Connect next to Claude Code or Cursor Agent. Disconnect removes PoHo’s hook again.

Let your AI ask PoHo

In the same place, under PoHo as a tool the agent can ask, you can connect Claude Code, Cursor and Codex. The AI can then ask PoHo where you stopped on a project, which earlier session dealt with something, and which of your projects use a technology. PoHo only reads; it never changes your projects. More in Let your AI ask PoHo (MCP).

Note: New chats pick up these changes. Chats that are already open are not affected. Connecting works only in the installed app, and only for tools found on this computer.

More tools

Connect more tools at the bottom of Your tools shows the tools that are not on this computer yet, with a link to get each one. Once installed, their chats join your project memory automatically.
