Safety and privacy

Privacy in short

No telemetry, no account, your code isn’t uploaded unless you ask; the few network calls PoHo makes and how it works offline.

What PoHo knows is stored on this computer: no account, no analytics, no telemetry, no crash reports sent anywhere. Your source code isn’t uploaded unless you ask: putting a project on GitHub pushes it to your account, and the AI add-on with your own Claude key sends short excerpts (listed below).

What stays on this computer

Your project list, notes, session memory, settings and pictures are stored only in your Windows user’s app data folder (%APPDATA%\PoHo Base). Errors go to a local crash log, never to us.

The only data we can ever receive is a bug report you choose to send. You see everything in it before it goes.

When PoHo uses the network

  • Updates: about every 30 minutes PoHo asks GitHub whether a newer version exists. Nothing about you is sent.
  • Tool versions: once a day it looks up the newest versions of tools like Node.js, Python, Git and Claude Code. You can turn the daily check off with Tool updates in Settings → Notifications; the Tools page in Settings still looks them up when you open it. Nothing about you or your projects is sent.
  • Skills → Discover: only when you open it (or when Home opens, if you turned on rising skills there), PoHo looks up public skill repositories on GitHub. Install downloads that one skill.
  • Project websites: while Check project websites is on, PoHo loads each project’s public site to take a picture and see that it responds, and asks the domain’s registry when the domain expires (only the domain name is sent).
  • GitHub: only if the GitHub CLI is installed and signed in, to see whether your repositories are public or private and to get the latest CI run.
  • Packages: when you click Check packages in a project’s Health, its package list is sent to the npm registry.
  • Claude plan limits: off until you turn on Show exact Claude limits; then Claude Code’s login is sent to Anthropic only.
  • The AI add-on: off until you choose it. With Ollama, text stays on this computer. With your own Claude key, PoHo sends Anthropic the README, CLAUDE.md, AGENTS.md (shortened), file names, text shown on your app’s screens, and what you asked your AI with its last replies (which can quote code), with keys, tokens and passwords removed first. Never whole source files.

The full list is in the Privacy Notice: Settings → Privacy & safety → Privacy.

Sync between computers

Settings → Account & sync says Not available yet: sync is not set up in this version, and everything is stored on this computer.

Using PoHo offline

PoHo works without internet. Finding projects, remembering sessions, continuing chats, snapshots and notes are all local. Only the things above that talk to a service wait until you are back online. Local AI through Ollama works offline too.

You decide

Choose what PoHo may read on the first screen, and change it any time in Settings → Privacy & safety.
