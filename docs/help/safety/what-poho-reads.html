Safety and privacy

What PoHo reads and writes

The folders, chat histories and settings PoHo reads, and the few places it writes, in plain words.

PoHo reads only the folders you chose and the chat history your AI tools already keep on this computer. It writes mostly to its own folder; anything it writes elsewhere is listed below, and nothing is read before you accept the first screen.

What it reads

  • Your project folders. Only the folders you added (or that PoHo found through your AI work, when you clicked Find my AI work). It looks at file names, the README, package files, git history and status, and sizes. It never searches your drives on its own.
  • Your AI tools’ chat history, while Read AI coding sessions is on:
    • Claude Code: ~/.claude/projects
    • Codex: ~/.codex/sessions
    • Gemini CLI: ~/.gemini/tmp
    • OpenCode: ~/.local/share/opencode
    • Antigravity: its plans, task lists and walkthroughs (not its conversations)
  • Skills and plugins in ~/.claude/skills (and the same folders for .agents, .cursor and .codex), inside your projects, and in installed Claude Code plugins. Reading them changes nothing.
  • Claude accounts: the email address in Claude Code’s profile, so you can tell accounts apart. Not the login itself, unless you turn on Show exact Claude limits.
  • Running programs, to show what a project is running on its map.
  • Obsidian’s list of vaults, if Obsidian is installed.
  • .env.example files: only the variable names. Your .env files and their values are never read.

What it writes

  • Its own folder: %APPDATA%\PoHo Base. Your project list, notes, settings, session memory, pictures and the session archive live here.
  • Snapshots in each project’s own .git folder, as hidden references. See Snapshots before AI sessions.
  • Your AI tools’ settings, only when you connect them (in Settings → AI agents): a small hook for Claude Code and Cursor, and PoHo as a tool for Claude Code, Cursor and Codex. PoHo keeps a backup of the original file next to it, and leaves a file alone if it can’t read it exactly. Ask Claude Code to keep them too (in Settings → Privacy & safety) changes one Claude Code setting the same way.
  • New skill folders in ~/.claude/skills, only when you click Install, and a newer copy of a skill PoHo installed when you click Update (the old one is kept in PoHo’s folder).
  • A deleted chat put back into your AI tool’s history folder, only when you click Restore the chat.
  • A PoHo folder in your Obsidian vault, only if you connect one.
  • Project files, only when you click: notes in CLAUDE.md and AGENTS.md, .gitignore lines for .env files, files you restore from a snapshot, a first commit when you put a project on GitHub, or a .lanes folder with its own branch when you make a lane for another Claude account.

Note: You can turn reading of AI sessions, window pictures and website checks on or off any time in Settings → Privacy & safety.
