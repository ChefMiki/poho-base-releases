Get back to work

Everything about one project

Each project has its own page: a way back in at the top, then the Map, Sessions, Notes and Setup tabs.

Click any project to open its page. At the top is one dark button that gets you back into the work; below it, four tabs: Map, Sessions, Notes and Setup.

To go back, use the back arrow in the top bar, Alt+Left, your mouse’s back button or Esc.

The header

  • The project’s picture, name and what it is about.
  • A status, for example Running with its local address.
  • Its stage and collections. Change them here.
  • The git branch and how many files are not committed.
  • The folder path. Click it to show the folder in File Explorer.
  • A star to add it to your favorites, and a ⋯ menu with every other action.

Getting back in

  • The dark button: Continue in … reopens the exact session where it ended. When that isn’t possible, Pick up with … starts an AI tool with notes on where you stopped, or Open in … opens your editor. Enter presses it when nothing else is focused.
  • Run starts the project’s dev server, when PoHo knows its run command. While it runs, you see Open localhost:… and Stop.
  • Open site opens the project’s public site, when it has one.
  • More ways has the rest: Restart this chat, pick up in any installed AI tool, Copy the notes, and open in Cursor, VS Code, Terminal or File Explorer.

The tabs

Map shows the project as a picture: the project in the centre, the AI tools that worked on it on the left, git, where the code lives and the dev server on the right, services below, and a red health node only when something is broken. Click a node for its details and actions. While the project runs, the centre comes alive; see See what a project is running. Under the map:

  • Welcome back: where you stopped, from your files and sessions.
  • Six numbers: Time with AI, Tokens processed, On disk, Commits, Changed by AI and Started. Click one for the breakdown.
  • Activity and Health.
  • Summary: what the project is about. With the AI add-on on, Summarize with AI writes it.

Sessions lists every AI chat in this project, newest first. Short chats are folded under Short chats. Choose one to see what it did: Done, Left open, the files it edited and what it changed. From there you can Continue it, open it In terminal or Restart it. New chat starts a Claude Code chat here.

Notes is your own notepad for the project, with At a glance and Activity beside it. See Your notes.

Setup is how the project is set up:

  • Run: the Run command and Local address PoHo uses. Your values stay when PoHo looks at the folder again.
  • For AI agents: which files an agent finds here (README, CLAUDE.md, AGENTS.md and others), and Write agent notes or Update agent notes. You see the files before anything is written.
  • Skills: skills used here and skills that fit.
  • Picture and Snapshots.
  • Archive project: hides the project in PoHo. Your files are not touched.

Note: If the folder was moved or renamed, the page says “This folder can’t be found.” Your notes and history are kept. Click Rescan after moving it back.
