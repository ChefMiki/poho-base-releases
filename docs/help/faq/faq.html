FAQ

Questions people ask

Short answers about price, AI, privacy, platforms, your files, your data, uninstalling and more.

Is PoHo free?

Yes. PoHo Base is a free preview for personal use. It is early software, so it may change or have bugs.

Do I need AI to use it?

No. Every core feature works without AI: finding projects, remembering sessions, continuing chats, snapshots and notes. The AI add-on (free local AI through Ollama, or your own Claude key) only adds summaries in plain words. See The AI add-on.

Does it upload my code?

Not unless you ask. Putting a project on GitHub pushes it to your own account. With your own Claude key, the AI add-on sends Anthropic short excerpts (the README, CLAUDE.md, file names, what you asked your AI and its last replies), never whole source files. Local AI through Ollama keeps everything on this computer. There is no analytics or telemetry. See Privacy in short.

Does it work on Mac or Linux?

No. PoHo Base is for Windows 10 and 11.

Which AI tools does it work with?

PoHo remembers sessions from Claude Code, Codex, Gemini CLI and OpenCode, and the plans and task lists Antigravity writes. Claude Code and Cursor can get a briefing at the start of every chat, and Claude Code, Cursor and Codex can ask PoHo questions as a tool. See Connect your AI tools.

Will it change or delete my files?

PoHo never deletes your files. It changes a project’s files only when you click, for example to add notes to CLAUDE.md or restore a file from a snapshot. See What PoHo never does.

Where is my data?

On this computer, in %APPDATA%\PoHo Base. Snapshots live in each project’s own .git folder. See What PoHo reads and writes.

Can I use it offline?

Yes. Everything that matters is local. Updates, tool versions, Discover and website checks wait until you are online. Local AI through Ollama works offline too.

Why does Windows block it?

PoHo’s app file isn’t code-signed, so Windows may show “Windows protected your PC” the first time. Click More info, then Run anyway. Updates after that are signed by PoHo’s developer and checked before they install. See Windows blocks PoHo.

Does it need admin rights?

No. It installs for your Windows user, with Desktop and Start menu shortcuts.

How do skills get here?

PoHo lists the skills already on your computer: in ~/.claude/skills and the matching folders of other tools, inside your projects, from installed Claude Code plugins, and skills Claude Code synced from your Claude account. You can add more with Install in Discover. See Your skills library.

What if an AI agent breaks my project?

PoHo saves a snapshot before every AI session in a git project. Open the project → Setup → Snapshots and restore the files. See Snapshots before AI sessions.

How do I uninstall PoHo?

Go to Settings → Privacy & safety and click Uninstall PoHo Base. It removes the app, its shortcuts, start-with-Windows, its hooks in Claude Code and Cursor, and PoHo as a tool in Claude Code, Cursor and Codex. Tick Also forget what PoHo remembered to remove its data too. Your project files are never touched.

How do I start fresh without uninstalling?

Settings → Privacy & safety → Start over. PoHo forgets its memory and opens at the welcome screen; a copy is kept in a backup folder.
