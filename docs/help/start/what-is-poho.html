Welcome

What PoHo does for you

PoHo Base remembers every project on your computer and where you stopped in each AI chat, and puts you back in with one click.

PoHo Base is the place you return to work. It knows the projects on your computer, remembers where you stopped in each one, in any AI coding tool, and takes you back there in one click.

It works fully without AI. There is no account, nothing to download besides the app, and PoHo never uploads your source files. Only with your own Claude key does it send short excerpts (README, CLAUDE.md, file names, your prompts and the last replies) to Claude.

Find

Your projects are already there. PoHo looks only in the folders you allow, or in the folders where your AI tools worked, and makes a page for each project from what is really on disk: its README, stack, scripts, git branch, last commit and uncommitted changes.

Press Ctrl P in the app, or Alt+Space from anywhere, to jump to any project or to something you once asked an AI.

Remember

PoHo reads the chat history of Claude Code, Codex, Gemini CLI and OpenCode, and the plans and task lists Antigravity writes. For every project it keeps:

  • what you asked, and which files changed;
  • what was left open;
  • time and tokens spent with AI.

It keeps a copy even after the AI tool deletes its old chats. Home always starts with the project you were last in and where you stopped.

Return

  • Continue reopens the exact chat where it ended, in your editor or a terminal.
  • Pick up with … starts any installed AI tool with a note of where the work stopped, so you can switch tools without explaining everything again.
  • New Claude Code and Cursor chats can start already knowing the project, your last session and what is left. See Connect your AI tools.

Keep it safe

PoHo never deletes your project files, and changes them only when you ask. It can only forget its own memory of a project. Before an AI session starts from PoHo, or in a connected Claude Code or Cursor, PoHo saves a snapshot of a git project, so you can put single files back later.

Note: AI is an optional add-on. A free local AI (Ollama) or your own Claude key adds summaries in plain words. Everything else works without it.
