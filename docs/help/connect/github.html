GitHub

Sign in with the GitHub CLI to see which projects are on GitHub, push in one click, put a project on GitHub safely and see CI results.

Sign in to GitHub once and PoHo shows which projects are on GitHub, private or public, and which have commits to push. It can also put a local project on GitHub for you, without uploading your .env files.

Sign in

PoHo uses the official GitHub CLI (gh). You sign in on github.com in your browser; PoHo never sees your password or token.

  1. Open Settings (Ctrl+,) and go to AI agents.
  2. Under Your AI tools, find GitHub and click Sign in.
  3. Click Sign in with GitHub. If the GitHub CLI isn’t installed, the button says Install GitHub CLI; PoHo installs it in a terminal you can see.
  4. Finish the sign-in in your browser. PoHo notices on its own.

Once you’re signed in, your open pull requests also appear in Needs you on Home.

What you see on each project

The git badge on a project tells you where it stands:

  • Connect to GitHub: not on GitHub yet. Click to put it there.
  • An arrow with a number: commits not pushed yet. Click to push.
  • Private or Public: on GitHub and up to date. Click to open the repository.

Put a project on GitHub

  1. Click Connect to GitHub on the badge, or open the project’s ⋯ menu and choose Put on GitHub….
  2. Check the repository name.
  3. Choose Private (“Only you”) or Public (“Anyone can see the code”). Private is the default.
  4. Read What PoHo will do, then click Create private repository (or public).

Before it uploads anything, PoHo adds .env files, packages and build output to .gitignore. It refuses if a .env file is already tracked by git, or if a file is too big for GitHub, and tells you how to fix it.

Note: PoHo doesn’t commit your work for you. A brand-new repository gets a first commit; otherwise PoHo commits only the .gitignore change and lists your uncommitted files as not included.

CI in Health

If a project on GitHub has workflows, its Health shows Tests (CI) with the latest run: Passing, Failing, Running now or Skipped. Click it to open the run on GitHub. Health is on the project page, below the map.

What is sent

Only while the GitHub CLI is signed in: after each scan PoHo asks GitHub, as you, whether your repositories are public or private, and Health asks for the latest CI run.
