Settings

Every setting, explained

Each Settings page and every setting on it, with what it does, in one place.

Open Settings from the ⚙ menu in the top bar, or press Ctrl ,. Pick a page on the left; every change is saved right away. Press Esc to close.

General

How PoHo looks, starts and stays at hand.

  • Appearance: Light, Dark or Match Windows.
  • Start with Windows: PoHo is ready when you sit down. Only in the installed app.
  • Start minimized: appears when Start with Windows is on. PoHo waits on the taskbar instead of opening in front of you.
  • Keep running in the tray: closing the window keeps PoHo in the tray, so projects you started keep running and updates install quietly.
  • Quick open: a key that opens PoHo’s search from any app. Choose Alt+Space, Ctrl+Alt+Space, Ctrl+Shift+Space, Ctrl+Alt+P or Off.
  • Welcome screen → Show it again: shows the first-run welcome. Your projects stay as they are.

Projects & folders

The folders PoHo reads. It never searches your drives on its own, and never deletes anything.

  • Folders PoHo reads: the list of folders you added. × (Stop watching this folder) makes PoHo forget its projects; files on disk are not touched.
  • Add folder: add another folder. See Add your project folders.
  • Keep only my AI work: review the list and keep just the folders where you worked with AI.
  • Scan depth: how many folder levels (2–6) below a folder you added PoHo looks for projects. Folders added from your AI work are one project each.

AI add-on

Optional. PoHo works fully without it. See The AI add-on.

  • No AI, Local AI (free, runs on this computer through Ollama, works offline) or Claude API (your own key, paid per use).
  • Local AI: install Ollama, Download the model, then Summarize all. Model (advanced) lets you pick another installed model.
  • Claude API: paste your Anthropic API key and click Save; Remove deletes it from PoHo. The key is stored on this computer, encrypted when Windows allows it.
  • Automatically summarize new and changed projects: shown once an AI is chosen.
  • Search by meaning: find sessions by meaning, not only the same words. Needs Ollama. Download and turn on downloads its model through Ollama; your sessions are read on this computer and nothing is sent anywhere.

AI agents

How Claude Code, Cursor and Codex learn where you stopped.

  • Connections: every AI tool PoHo found, and whether it is connected. Check again looks once more.
  • Agent memory → Briefing at the start of a session: Connect Claude Code or Cursor Agent, and new sessions get a short briefing. See What your AI is told.
  • Agent memory → PoHo as a tool the agent can ask: Connect Claude Code, Cursor or Codex. See Let your AI ask PoHo.
  • Obsidian → Keep my projects in Obsidian: pick a vault and Connect; Update now writes the notes again. See Obsidian.
  • Claude accounts: Add account to use more than one Claude Code account; each keeps its own login and history. See Claude accounts and limits.
  • Let agents see all my projects: off, an agent asking PoHo sees only the project it works in. Off is safer. Secrets are always hidden.
  • Show exact Claude limits: asks Anthropic how much of your 5-hour and weekly limit is used. Off, PoHo estimates from your sessions.

Editor & terminal

  • Preferred editor: Cursor or VS Code, where Open and Continue open your projects.
  • Terminal and Shell: which terminal app and shell start your AI tools. Automatic picks the best one found. Try it opens a test terminal.

Tools

Node.js, Python, Git, Claude Code and the rest: your versions and the newest ones. Update runs the command in a terminal you can watch. Check again looks again. Tell me once a day when there is an update is the same switch as Tool updates under Notifications.

Notifications

  • Claude is waiting for you: when Claude needs your permission or an answer.
  • A long task is done: when an agent finishes something that took two minutes or more.
  • End-of-day reminder: once a day, at the hour you pick, when today’s projects have work that is not committed.
  • Tool updates: once a day, when one of your tools has a new version.

Privacy & safety

  • Read AI coding sessions, Take pictures of app windows, Check project websites: what PoHo may do. See What PoHo reads and writes.
  • Session archive: keeps compressed copies of AI chats, so you can still search and continue them after Claude Code deletes them (after 30 days). Ask Claude Code to keep them too makes Claude Code keep them for ten years.
  • Terms and Privacy: the documents you accepted.
  • Start over: PoHo forgets what it remembered and opens at the welcome screen. Your files are never deleted.
  • Uninstall PoHo Base: only in the installed app. See What PoHo never does.

Updates

  • Check for updates or, when one is ready, Restart now.
  • Signed updates: an update that is not signed, or was changed on the way, is refused.
  • Get beta versions first: get new versions before everyone else. See Updates and beta versions.
  • Go back to version …: appears after an update, if the new version gives you trouble.

Account & sync

  • Name: this computer’s name.
  • Sync between computers: shows Not available yet. Sync is not turned on in released versions; everything is stored on this computer.
