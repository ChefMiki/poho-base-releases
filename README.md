# PoHo Base

**Pick up where you left off.** PoHo Base finds every project on your computer, remembers every AI coding session (Claude Code, Codex, Gemini CLI, OpenCode), and takes you back to where you stopped in one click.

This repository only hosts the downloads. The app is a free preview for Windows 10 and 11.

## Website

**[mikicarbre.github.io/poho-base-releases](https://mikicarbre.github.io/poho-base-releases/)**

## Download

**[Download PoHo Base for Windows](../../releases/latest/download/PoHo-Base-win-x64.zip)**

Installed copies update themselves: every update is signed, and PoHo only installs updates with a valid signature.

## Install

1. Unzip the file anywhere, for example your Downloads folder.
2. Open the **PoHo Base** folder and double-click **PoHo Base.exe**.
3. If Windows shows *“Windows protected your PC”*, click **More info**, then **Run anyway**. PoHo Base is new and not code-signed yet.
4. Choose what PoHo may do, accept the Terms of Use and Privacy Notice, and click **Accept and install**. It installs for your Windows user (no admin rights) and adds Desktop and Start menu shortcuts. You can then delete the downloaded folder.

## Privacy

Everything stays on your computer: no account, no analytics, and your code is never uploaded. You choose what PoHo reads on first run and can change it any time in **Settings → Privacy**.

## Uninstall

**Settings → Privacy → Uninstall PoHo Base.** Your project files are never touched.
